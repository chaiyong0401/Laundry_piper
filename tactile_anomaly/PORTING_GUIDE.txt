========================================================================
XELA 촉각 센서 기반 이상 감지 API 이식 및 사용 설명서 (PORTING GUIDE)
========================================================================

이 문서는 본 촉각 이상 감지(tactile_anomaly) API 패키지를 다른 로봇 시스템 및 
동일한 모델의 XELA 센서 환경으로 이식하여 사용할 때 필요한 제약 사항, 
데이터 수집 및 학습 방법, 그리고 실시간 추론 실행법을 설명합니다.

------------------------------------------------------------------------
0. 필수 실행 환경 및 패키지 설치 방법 (Prerequisites)
------------------------------------------------------------------------

본 API 패키지를 실행하기 위해서는 Python 3.8 이상 환경이 요구되며, 필수 의존 라이브러리들이 설치되어 있어야 합니다. 
동일한 패키지 폴더 내에 포함된 `requirements.txt` 파일을 활용하여 아래와 같이 환경을 손쉽게 세팅할 수 있습니다.

* 설치 명령어 (Conda 또는 Python 가상환경을 활성화한 상태에서 실행을 권장합니다):
  pip install -r requirements.txt

* 주요 핵심 의존성 목록:
  - torch (GRU-AE 딥러닝 모델 추론 및 연산)
  - numpy, scipy (수치 해석, 리샘플링 및 신호 처리)
  - scikit-learn, joblib (StandardScaler 데이터 정규화 및 스케일러 파일 직렬화)
  - matplotlib (학습 곡선 및 검증 평가 플롯 시각화)
  - websocket-client (xela_bridge.py에서 XELA 서버 WebSocket 데이터 수신)

------------------------------------------------------------------------
1. 타 시스템 이식 시 핵심 제약 사항 (주의 사항)
------------------------------------------------------------------------


* 센서 장착 방향 (Orientation)
  - 그리퍼 핑거에 부착된 센서의 물리적 방향(X, Y, Z축 배열)이 틀어지면 
    6D 피처(unit_x, unit_y, unit_z 등)의 극성과 크기가 변하여 이상 감지 모델이 
    정상 파지를 이상(anomaly)으로 잘못 오판할 수 있습니다. 
    가능한 한 센서 장착 방향을 원본 로봇과 일치(센서의 선이 그리퍼 안쪽 - 로봇 방향으로)시키거나, 방향이 다를 경우
    데이터를 다시 수집하여 모델을 학습해야 합니다.

* 로봇 및 그리퍼 동작 특성 (Dynamics)
  - 그리퍼가 닫히는 속도, 쥐는 힘(Effort/Current), 파지 직후 로봇 팔의 가속도로 
    인한 관성 노이즈 등은 시계열 데이터의 형태와 스케일을 결정합니다. 
    이러한 조건이 변경되면 기존에 학습된 스케일러(StandardScaler) 및 
    이상 감지 임계값(Threshold)이 맞지 않게 되므로, 이식 후 성공 데이터 재수집 
    및 학습이 권장됩니다.

* XELA 센서 정규화 파일 (taxel_minmax_norm.npy)
  - xela_bridge.py는 센서 입력의 차분을 구하기 전에 각 taxel에 대해 min-max 정규화를 수행합니다. 이 정규화 정보는 taxel_minmax_norm.npy 파일에 저장됩니다.
  - 센서 감도와 그리퍼에 따라 min-max 기준값(최솟값 및 가동 범위)이 달라지므로, 새 환경 구축 시 센서 데이터를 수집해 taxel_minmax_norm.npy 파일을 새로 캘리브레이션/생성하여 교체 하는 것을 권장합니다.
  - xela_bridge.py 실행 시 --minmax 옵션으로 경로를 임의 지정할 수 있으며, 미지정 시 기본적으로 tactile_anomaly/taxel_minmax_norm.npy 파일을 불러옵니다.
  
  - 기본적으로 파이퍼 로봇으로 획득한 값을 넣어 두었습니다.

1-1. 의존 패키지 및 코드 동작 검증 (example.py)
------------------------------------------------------------------------
의존성 라이브러리(PyTorch, Scikit-learn 등)가 올바르게 설치되었는지 확인하고 
이중 채널 감지 로직의 동작 테스트를 수행하기 위해 제공되는 가상 시뮬레이션 스크립트입니다.

* 실행 명령어:
  python3 -m tactile_anomaly.example

* 설명:
  - 실행 시 임시 디렉토리에 가상(mock) 스케일러 및 모델 가중치 파일을 생성합니다.
  - 가상의 센서 입력을 가동시켜 [테스트 1] 정상 파지, [테스트 2] Channel B 이상 감지, [테스트 3] Channel A 이상 감지가 올바르게 작동하는지 전 과정을 시뮬레이션하여 검증합니다.
  - 테스트 완료 후 생성된 임시 파일은 자동으로 초기화 및 정리됩니다.
  


------------------------------------------------------------------------
2. 학습 데이터 수집 및 모델 사용 가이드
------------------------------------------------------------------------
 ########################################################################################
 -> step1,2는 학습 데이터 수집 및 학습 과정이기 때문에 단순 검증을 확인하기 위해선 step3 참조 부탁드립니다.
 ########################################################################################
■ STEP 1: 정상 파지(Success) 데이터 수집
  새 로봇 환경에서 정상적인 파지 작업을 반복 실행하여 센서 시퀀스 데이터를 저장합니다.

  1. 데이터 포맷: 
     - 각 에피소드는 [T, D] 크기의 float32 numpy array 파일 (.npy)로 저장됩니다.
     - D는 사용 방식에 따라 6D feature 또는 48D raw taxel 데이터입니다.
  2. 파일 명명 규칙:
     - {prefix}_{timestamp}_{label}.npy 구조를 따라야 합니다.
     - 예: grasp_20260520_150000_success.npy
     - 평가를 위해 실패 데이터(failure)나 외란 데이터(perturbation)도 함께 
       수집하여 저장하는 것이 좋습니다.

■ STEP 2: 스케일러 피팅 및 모델 학습/캘리브레이션
  수집된 정상 파지 데이터를 학습 디렉토리(예: grasp_data)에 모아두고 
  train_gru_ae.py 스크립트를 사용하여 학습을 진행합니다.

  * 학습 명령어 예시 (48D raw taxel 데이터 사용, relative 변환 없이 학습 시):
    python train_gru_ae.py \
      --model grasp \
      --data_dir ./grasp_data \
      --epochs 1000 \
      --batch_size 32 \
      --windowed \
      --win_stride 10 \
      --use_raw \
      --relative none \
      --eval

  * 출력 결과물 (학습 후 생성되는 필수 파일):
    1. grasp_gru_ae_raw.pt    : 학습 완료된 GRU Autoencoder 모델 가중치 파일.
    2. grasp_scaler_raw.pkl   : 학습 데이터 정규화에 사용된 StandardScaler 객체.
    3. grasp_threshold_raw.npy : Channel A (점진적 slip 감지용 GRU-AE) 임계값.
    4. grasp_threshold_b_raw.npy : Channel B (급격한 impact/drop 감지용 MRL delta) 임계값.
    5. grasp_infer_cfg_raw.pkl : 학습에 사용된 seq_len, relative 등의 옵션 정보.


■ STEP 3: 실시간 감지 서버 (xela_bridge) 구동

* XELA 센서 하드웨어 연결 사전 조건:
  - xela_bridge.py가 정상 작동하려면, 물리적인 센서 시리얼/USB 포트 연결을 관리하는 XELA 드라이버 서버인 `./xela_server` 또는 `ros2 run xela_server_ros2 xela_service.py`가 백그라운드에 먼저 실행되어 있어야 합니다.
  - 해당 서버가 실행되면 자동으로 로컬 호스트에 WebSocket API(기본값: localhost:5000)를 개설하므로, xela_bridge.py는 이 네트워크 스트림에 접속하여 데이터를 실시간 수신하게 됩니다. 
  

  *** 실행 명령어 예시 1 (프리셋 사용 시/권장): ****
    - 파지 구간 (grasp_05_raw 프리셋) 모니터링:
      python3 -m tactile_anomaly.xela_bridge --preset grasp_05_raw
    
    - 이송 구간 (transport_05_raw 프리셋) 모니터링:
      python3 -m tactile_anomaly.xela_bridge --preset transport_05_raw --max_norm_gate 0.3

  * 실행 명령어 예시 2 (직접 경로 지정 시 - 기본 연결 값 사용):
    # 연결 설정(localhost:5000, 센서 ID 1, TCP 포트 9001) 및 정규화(minmax) 파일은 
    # 기본값으로 자동 로드되므로, 아래와 같이 새로 학습한 모델 경로들만 명시하여 실행할 수 있습니다.
    python3 -m tactile_anomaly.xela_bridge \
      --model ./grasp_data/grasp_gru_ae_raw.pt \
      --scaler ./grasp_data/grasp_scaler_raw.pkl \
      --thr_a ./grasp_data/grasp_threshold_raw.npy \
      --thr_b ./grasp_data/grasp_threshold_b_raw.npy \
      --cfg ./grasp_data/grasp_infer_cfg_raw.pkl


■ STEP 4: 실시간 모니터링 클라이언트 (monitor_bridge) 실행
  별도의 터미널에서 모니터링 클라이언트를 실행하여 센서 데이터 추론 상태를 실시간으로 확인할 수 있습니다.

  * 실행 명령어:
    python3 -m tactile_anomaly.monitor_bridge

  * 상태 모니터 사용법:
    1. xela_bridge 및 monitor_bridge가 실행되면 초기 상태는 `IDLE`로 대기합니다.
    2. 로봇 그리퍼가 물체를 완전히 닫기 전, 터미널에서 **Enter 키**를 누릅니다.
    3. Enter 키 입력 시 xela_bridge에 RESET 신호가 전송되어 누적 버퍼가 초기화되고 실시간 추론이 시작됩니다.
    4. 초기 seq_len(50프레임) 동안 버퍼를 채울 때는 `IDLE` 상태를 유지하다가, 버퍼가 완료되면 `NORMAL` (정상 파지) 또는 `ANOMALY` (이상 감지)로 전환됩니다.
    5. 이상(anomaly)이 감지되면 `ANOMALY` 상태가 락(latch)되므로, 다음 파지 시도 시 다시 Enter를 눌러 리셋해 주어야 합니다.

3. Python 라이브러리 직접 연동 규격 (Import)
------------------------------------------------------------------------

파이썬 기반 로봇 제어 코드에서 이 API를 패키지로 직접 import하여 판단 루프를 구동할 수도 있습니다.

* 구현 예시:
  ```python
  import sys
  # 패키지 경로를 추가합니다 (필요한 경우)
  sys.path.append("/path/to/tactile_anomaly_parent_directory")
  
  from tactile_anomaly import DualChannelDetector
  
  # 체크포인트 로드 (학습 시 생성된 파일들을 지정)
  detector = DualChannelDetector.from_checkpoint(
      model_path       = 'grasp_data/grasp_gru_ae_raw.pt',
      scaler_path      = 'grasp_data/grasp_scaler_raw.pkl',
      threshold_a_path = 'grasp_data/grasp_threshold_raw.npy',
      threshold_b_path = 'grasp_data/grasp_threshold_b_raw.npy',
      infer_cfg_path   = 'grasp_data/grasp_infer_cfg_raw.pkl'  # 생략 가능
  )
  
  # 에피소드 시작 시 버퍼 초기화 (반드시 호출)
  detector.reset()
  
  # 제어 루프 진입
  while robot_is_grasping:
      # xela 센서로부터 프레임 획득 (예: 6D feature 및 48D raw)
      # frame_6d: [mrl, norm, max_norm, unit_x, unit_y, unit_z] (6,)
      # raw_frame: [cum_x(16) + cum_y(16) + cum_z(16)] (48,)
      frame_6d, raw_frame = get_xela_sensor_data() 
      
      # 판단 갱신
      result = detector.update(frame_6d, raw_frame=raw_frame)
      
      if result['anomaly']:
          print(f"이상 감지! 감지 채널: {result['channel']}")
          print(f"  Ch-A 점수: {result['score_a']:.4f} (임계치: {detector.threshold_a})")
          print(f"  Ch-B 델타: {result['delta_b']:.4f} (임계치: {detector.threshold_b})")
          # 예외 처리 또는 파지 중단 로직 실행
  ```
